## Buy

* 3–4 wood screws to fix the Fixed Rotating Base to the desk (or use a C-clamp base instead).

## Assemble

1. Screw the Fixed Rotating Base to the desk, near the back edge on your mic side.
2. Seat the Base Link Joint in the base; the Set Screw locks rotation. Leave it loose if you want the boom to swing away.
3. Raise the 275 mm link almost vertical, then run the 250 mm link forward and slightly down toward your mouth.
4. Choose the Microphone Mount Base with **1 dot or 2 dots** so it pairs with the end of the 250 mm link (● meets ●●).
5. Attach the mic-side arm (Short / Standard / Long “Screw”) with the small mic link screw, washer and nut, then fit your mic.
6. Run the XLR/USB cable along the links and snap on the cable clips. Test-fit the 16 mm clip first and go up or down a size.

!!! tip "Tips"
    * For a “swing-away” boom, keep the base rotation free and keep the link joints tight.
    * Heavy broadcast mics: shorten the forearm to 200–225 mm before thickening the prints.
    * Big printer? `LINK - 300mm` gives a taller riser (it doesn't fit a 256 mm bed).

## Variations

* **Clamp version (Standard tier):** Rotating C-Clamp instead of the Fixed Rotating Base.
* **Low-profile desk boom:** 200 mm + 175 mm links on a Weighted Base (Medium).
