**Print profile:** Heavy payload: PETG, 5–8 walls, 30–50 % infill on every structural part

## Buy

* 8× M4 screws + washers for the monitors (length depends on the monitor, typically 8–12 mm).
* 3–4 wood screws for the Fixed Rotating Base.

## Assemble

1. Screw the Fixed Rotating Base down; a desk clamp alone isn't enough for this lever arm.
2. Build the spine: 150 mm link vertical → 3-Way Branch Link → 275 mm riser, all vertical, so the monitors' weight goes straight down the column.
3. Lower monitor: side output of the branch → 50 mm Payload Link → VESA 75 plate.
4. Upper monitor: top of the 275 mm riser → 50 mm Payload Link → VESA 75 plate.
5. Bolt the monitors on with M4 screws **before** tightening the arm, then set the heights and lock every joint firmly.

!!! tip "Tips"
    * The official guidance is “intended for items weighing less than 10 lbs.” That's the total, not per arm. Full-size desktop monitors (3–6 kg each) belong on a metal arm.
    * Keep the spine vertical. Every degree of lean turns weight into joint torque.

## Variations

* **Single floating monitor:** base → 150 mm → 200 mm (horizontal) → Payload Link → VESA 100.
* **Wall version:** Fixed Wall Mount → 150 mm → Payload Link → VESA 75 for a wall-hung status screen.
