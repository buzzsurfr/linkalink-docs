# Hardware

Link-A-Link is **primarily printed**: every link joint's screw, washer and nut, and every base and payload fastener, is an STL.
You only buy hardware for the parts that interface with the outside world.

## What needs what

| If you print… | You'll need |
|---|---|
| Anything with links only | **Nothing**. All joint hardware is printed |
| 1/4-20 Mount | A 1/4-20 bolt or thumb screw |
| VESA Mount | M4 screws + washers (length per monitor) |
| Fixed Rotating Base, Rail System | Wood screws (countersunk) |
| Fixed Wall Mount | Wall anchors + screws |
| Weighted Base | Ballast: sand, steel shot, BBs |
| Tensioned Clamps, T-Claw, Tensioned Laptop Mount, Phone Mount | Rubber bands |
| Phone Mount (Heat-Insert arms), Tensioned Laptop Mount arms | Heat-set inserts (size not stated; measure the bore) |
| MagSafe Mount | A MagSafe puck or magnet ring |
| Spring Clamp | A little TPU filament for the jaw inserts |

## Categories from the official list

### 1/4-20 hardware
Camera mounts, action cams, lighting, tripod accessories. **1/4-20 bolts, thumb screws, nuts.**

### Wood screws
Fixed desk mounts, workbench mounts, permanent installs. Length depends on the surface.

### Wall anchors
Wall mounts and permanent wall installs. Drywall anchors plus suitable screws, or masonry plugs.

### VESA hardware
Monitor mounts. **M4 screws** (most common) + **M4 washers**. Some monitors need different lengths.

### Rubber bands
Tensioned grips, adjustable holders, flexible retention. Size varies by application.

## Printed hardware families

The system uses a few sizes of printed fastener. They are **not** interchangeable across families:

| Family | Parts | Used for |
|---|---|---|
| **Link hardware** | Screw 41.9 mm · cone Washer 38.1 mm · Threaded Nut 38.1 mm | Every rosette-to-rosette joint. The nut's tabs lock into the rosette; you turn the T-head screw |
| **Base / payload screw** | Screw ~23–62 mm · cone Washer 30.5 mm | Base Link Joint → base; payload mount → Payload Link |
| **Small pivot hardware** | Screw ~34–55 mm · Washer 26.2 mm · Nut 24.1 mm | Swivel payload link, mic mount 2nd pivot, T-Claw arm joints |
| **Set screws** | 24 × 28 mm | Lock rotation on Rotating C-Clamp and Fixed Rotating Base |
