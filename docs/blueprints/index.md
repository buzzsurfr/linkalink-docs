# Blueprints

Complete, printable configurations: the setups from the product page plus a few more, each with a scale side-view, a full print list with folder paths, bought hardware, and assembly order.

!!! info "How to read a blueprint"
    **Orange letters** in the drawing match the **Key** and **Print list**. Gray bars are Standard Links, lighter bars are Modular Link bodies, **orange bars** are Payload Links. Circles are toothed joints; each one needs a link hardware set.
