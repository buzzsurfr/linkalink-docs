This is an **unofficial**, community-written reference by an Ultimate-tier backer. It is **not affiliated with or endorsed by 3D Printing Builds**.

Get the library from [3D Printing Builds](https://3dprintingbuilds.com/link-a-link/); it's worth it. Every image on this site is either drawn from scratch or **rendered here from the part geometry** for identification.

## What's inferred

Where the library doesn't say how something works, this guide says so in a **question** callout marked *Inferred*. The main ones:

* Ballast capacity of the Weighted Bases (estimated from cross-sections).
* How the Ball Joint Link attaches to the arm.
* The mic interface on the Microphone Mount.
* The effective length of an assembled Modular Link.
* All blueprint reach/height numbers are **geometric estimates** from link pitch lengths, not measurements.
* The torque bands in [Design Your Own](../blueprints/design-your-own.md) and the [Load Calculator](../blueprints/load-calculator.md), and printed-part masses (estimated from volume and surface area).
* *Why* the ●/●● rosettes are clocked differently. The offset itself is measured; the purpose is inferred.

Measure your own prints and correct this guide as you go.

## Maintaining this site

Source: [github.com/buzzsurfr/linkalink-docs](https://github.com/buzzsurfr/linkalink-docs). Corrections and additions are welcome via issues or PRs.

This site is built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/). The catalog, file index and blueprint pages are generated by `gen/build.py` from the data in `gen/*.py`. Edit the data, then rebuild:

```bash
pip install mkdocs-material
python gen/build.py      # regenerates docs/ pages from data
mkdocs serve             # live preview at http://127.0.0.1:8000
mkdocs build             # static site in site/
```
