## Buy

* 1× 1/4-20 bolt or thumb screw (length to suit your device; ≈ 10–12 mm of thread engagement)

## Assemble

1. Measure your desk thickness and print the Fixed C-Clamp base whose opening is the next size up (40–80 mm).
2. Clamp the base to the desk edge; thread the 60 mm clamp screw in from below with the Round Pad on its tip.
3. Join the **200 mm** link to the clamp's rosette with one link hardware set (screw → washer → rosettes → nut). Leave it finger-loose.
4. Join the **150 mm** link to the free end of the 200 mm link. Remember **● meets ●●**.
5. Add the **50 mm Payload Link** to the end of the 150 mm link. Print the Payload Link variant (1 circle or 2 circles) that pairs with the end you are attaching to.
6. Assemble the 1/4-20 Mount (the two Screw Holder halves capture your bolt) and fix it to the Payload Link.
7. Pose the arm, then tighten each joint from the base outward, using the tool for the last bit of torque.

!!! tip "Tips"
    * If a joint slips under the camera's weight, tighten it before you add walls or infill. Most slip comes from joints that are too loose.
    * Swap the 50 mm payload link for the **Swivel** version if you want pan without loosening a joint.

## Variations

* **Clamp-free:** replace the clamp with the Round Base 200 mm + Desk Mount Link Joint.
* **Phone:** replace the 1/4-20 Mount with the Phone Mount (small) or the Small Tensioned Clamp.
