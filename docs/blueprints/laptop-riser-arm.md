## Buy

* Optional: a few rubber bands if you choose the **Tensioned Laptop Mount** instead.
* Optional: heat-set inserts for the Tensioned Laptop Mount arms (`Arm - Heat Insert`). Size isn't specified in the library, so measure the hole.

## Assemble

1. Print the Rotating C-Clamp for your desk thickness. Assemble clamp screw, then drop in the Base Link Joint and lock it with the Set Screw once you like the swing angle.
2. Build the zig-zag: first 200 mm link rising about 40°, second 200 mm link folding back down about 20°. A “Z” keeps the load close to the clamp.
3. Attach the 50 mm Payload Link, then the Laptop Mount tray with its screw and washer. The Laptop Mount has supports enabled in the supplied 3MF; keep them.
4. Tilt the tray back slightly (≈ 10–15°) so the laptop can't slide off the front lip.
5. Tighten every joint firmly with the tool. This build puts the most torque of all the blueprints on the first joint.

!!! tip "Tips"
    * Weight × horizontal distance is what the first joint has to hold. Keep the tray **over** the clamp's footprint where you can.
    * Print the two long links flat (as supplied) in PETG; don't scale them.

## Variations

* **Standing desk side-car:** add a 125 mm link for more height, but drop to a tablet-weight device.
* **Grip instead of tray:** Tensioned Laptop Mount (rubber-band tensioned arms) holds the laptop without relying on the lip.
