## Buy

* Wall anchors + screws suited to your wall (drywall anchors, or plugs for tile/masonry).
* Rubber bands for the clamp arms.

## Assemble

1. Print the **Hole Pattern Template** first (1.3 mm thin), tape it to the wall, level it, and mark the holes.
2. Drill, set the anchors, and screw the Fixed Base to the wall. Try to hit a stud if you can.
3. Attach the Wall Mount Base Link Joint with its screw and washer.
4. Chain: 175 mm link → 150 mm link → Swivel Payload Link → Medium Tensioned Clamp.
5. Set joint tension so the arm holds pose but can still be folded flat against the wall by hand.

!!! tip "Tips"
    * Mount at eye level beside, not above, the cooktop.
    * Portrait/landscape is a swivel turn; no need to touch the arm joints.

## Variations

* **Garage/workshop screen:** same arm with a VESA 75 plate for a small monitor.
* **Doorbell/intercom tablet:** swap to the Large Tensioned Clamp for 11″+ tablets.
